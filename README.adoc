== 🧠 Vision MASTER CLASS
C-Learning v5.0.0 est la version ultime du programme d’apprentissage du langage C.
Cette édition MASTER CLASS transforme le dépôt en une formation complète couvrant :

- Les bases du C (v1.0)
- La programmation structurée (v2.0)
- La mémoire dynamique & pointeurs avancés (v3.0)
- L’architecture logicielle & modules (v4.0)
- L’optimisation, la sécurité, le debugging & les projets réels (v5.0.0)

Objectif : **former un développeur C professionnel**, capable de créer des logiciels
robustes, performants, sécurisés et maintenables.

== 🏗️ Structure du projet (v5.0.0)
- *src/basic/* : fondamentaux du C (v1.0)
- *src/intermediate/* : structures, fichiers, modularité (v2.0)
- *src/advanced/* : pointeurs avancés, mémoire dynamique, heap, stack (v3.0)
- *src/architecture/* : modules, API internes, organisation logicielle (v4.0)
- *src/masterclass/* : optimisation, sécurité, debugging, projets réels (v5.0.0)

- *exercises/basic/* : exercices débutants
- *exercises/intermediate/* : exercices intermédiaires
- *exercises/advanced/* : exercices avancés
- *exercises/masterclass/* : défis experts & projets complets

- *docs/* : documentation complète (cours, guides, références)
- *Makefile* : compilation multi-niveaux (basic → masterclass)

== 🚀 Compilation (v5.0.0)
=== Compilation standard
[source,bash]
----
make all
----

=== Compilation par niveau
[source,bash]
----
make basic
make intermediate
make advanced
make masterclass
----

=== Compilation optimisée (MASTER CLASS)
[source,bash]
----
make optimize
----

Active :
- -O3 optimisation agressive
- -march=native
- -flto (Link Time Optimization)
- -funroll-loops
- -DNDEBUG

=== Compilation sécurisée
[source,bash]
----
make secure
----

Active :
- -Wall -Wextra -Werror
- -fstack-protector-all
- -D_FORTIFY_SOURCE=2
- -Wshadow -Wconversion -Wdouble-promotion
