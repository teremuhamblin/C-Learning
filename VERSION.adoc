== 📌 Politique de versionnage
Le projet utilise le versionnage *SemVer* :
- MAJEUR : changements structurels
- MINEUR : ajouts pédagogiques
- PATCH : corrections mineures

== 🛡️ Stabilité
- `main` : stable
- `developp` : en développement
- `feature/*` : expérimental
