== 📌 Politique de versionnage (SemVer MASTER CLASS)
------------------------------------------------------------

- **MAJEUR** : changements structurels, architecture, sécurité, refonte globale  
- **MINEUR** : ajouts pédagogiques, nouveaux modules, nouvelles fonctionnalités  
- **PATCH** : corrections mineures, documentation, ajustements  

Règle :  
> Toute version MAJEURE doit être validée par un reviewer MASTER CLASS.
